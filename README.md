## Run it

```sh
node main.ts /output
```

This writes the entry to `/output/entry.txt` (pass a different directory as the first argument for a local run). Node 22+, standard library only, no network — the output is deterministic.

## The entry

One rant, 271 characters, about a free-tier cloud box with narcolepsy: it falls asleep every fifteen minutes, mid-sentence, and waking it up costs more time — and credits — than using it. The punch lands in the first sentence, and the kicker is the roommate who charges rent every time he opens his eyes.

## How it is judged

A furious judge model reads entries two at a time and picks the one that lands hardest — funniest rant about a specific everyday annoyance wins. The gate is 1–400 characters of UTF-8 text; this entry is 271.
